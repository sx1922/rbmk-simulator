# web/js/ — 前端模块

| 模块 | 职责 |
|------|------|
| `engine.js` | 物理引擎（点堆动力学、氙/空泡/ОЗР、保护、汽水分离器等） |
| `app.js` | 主循环与生命周期（菜单/值班/终局/结算）、统计、输入 |
| `menu.js` | 主菜单与整定设置 |
| `props.js` | 桌面道具（规程手册 / 电话 / 茶炉 / 计算器 / 剂量计 / 号码簿） |
| `scenario.js` | 场景事件运行时（历史重演模式剧本） |
| `endless.js` | 无尽运营（逐月结算 / 事件 / 班组 / 成就） |
| `challenge.js` | 挑战模式（15 分钟限时排障） |
| `tutorial.js` | 第一幕教学引导 |
| `pause.js` | 暂停菜单 |
| `debrief.js` | 结算画面与历史匹配度 |
| `audio.js` | 程序化音效（底噪 / 盖格 / 电话 / 演出） |
| `render.js` | 表盘与仪表渲染 |
| `bridge.js` | ESM 桥接（加载 `lib/scoring.js` / `lib/save.js`） |
| `boot.js` | 开机动画 |
