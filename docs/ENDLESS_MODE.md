# 无尽模式 — Бесконечный Режим

## 概述

无尽模式是核电站运营模拟。玩家扮演值班班长，管理一座核电站的持续运行。没有剧本终点，直到失败条件触发。

核心循环：发电 → 赚钱 → 维护/换料 → 应对事件 → 继续发电

---

## 时间系统

| 单位 | 时长 | 说明 |
|------|------|------|
| 游戏秒 | 1秒 | 最小操作粒度 |
| 班次 | 8小时 | 玩家一个操作周期 |
| 日 | 3个班次 | 早/中/夜 |
| 月 | 30天 | 经济结算周期 |
| 燃料周期 | 12-18个月 | 换料大修间隔 |

**时间流速：**
- 正常：1x（1游戏秒 = 1秒）
- 快进：4x / 16x / 64x
- 暂停：0x（下达指令、查看面板）
- 紧急事件自动降回 1x

**班次交接：**
- 每8小时自动触发交接
- 交接时显示班次报告（本班次发电量、异常事件、人员状态）
- 玩家可选择：继续值班 / 交班（跳过到下一班）
- 交班期间电站由AI运行，可能出事（概率低，但后果由玩家承担）

## 经济系统

### 收入

| 来源 | 计算 | 备注 |
|------|------|------|
| 售电 | 功率(MW) × 时间(h) × 电价 | 电价随供需波动 |
| 容量奖金 | 可用率 > 90% 时额外奖励 | 月度结算 |
| 调峰补贴 | 响应电网调度指令 | 随机事件触发 |

### 支出

| 项目 | 频率 | 备注 |
|------|------|------|
| 燃料采购 | 换料时 | 大头，一次性 |
| 日常维护 | 月度 | 固定 + 设备老化附加 |
| 人员工资 | 月度 | 按编制 |
| 监管罚款 | 事件触发 | 安全违规、超标排放 |
| 大修费用 | 换料周期 | 停堆 = 零收入 + 高额支出 |
| 设备更换 | 事件触发 | 泵、阀门、仪表等 |

### 电价模型

```
基础电价 = 0.02 ₽/kWh（固定，2 戈比/kWh，符合 1986 年苏联工业电价水平）
市场波动 = ±30%，周期约7天（正弦 + 噪声）
季节系数 = 冬季1.2 / 夏季1.1 / 春秋1.0
紧急折扣 = 电网要求降功率时，电价×0.7
```
货币单位：卢布（рубль / ₽）。1 卢布 = 100 戈比。

### 破产条件

- 连续3个月净亏损 → 警告
- 连续6个月净亏损 → 电站被接管，游戏结束

## 燃料循环

### 燃耗模型

每根燃料棒独立追踪：

```
燃耗(MWd/kg) += 功率密度 × 时间
反应性贡献 = f(燃耗)  // 随燃耗增加，反应性下降
```

- 初始装载：全堆芯新燃料
- 燃耗限值：达到设计限值（如 40 MWd/kg）必须换出
- 换料策略：玩家决定换多少根、换哪些位置（影响功率分布）

### 换料大修

- 触发条件：玩家主动决定 / 燃耗达到限值强制
- 停堆时间：30-60天（玩家选择检修范围）
- 期间：零发电收入，支付大修费用
- 大修内容：换料 + 可选设备检修（花更多钱减少未来故障率）
- 决策点：多停几天做彻底检修 vs 尽快恢复发电

### 功率分布

- 堆芯分为若干区域（简化为 5×5 或 7×7 网格）
- 换料时玩家安排新燃料位置
- 功率不均匀 → 局部过热风险 → 事件

## 人员系统

### 编制

| 岗位 | 人数 | 职责 |
|------|------|------|
| 值班班长（玩家） | 1 | 决策 |
| 操纵员 | 2-3 | 执行操作，响应速度取决于技能 |
| 现场操作员 | 2-4 | 现场巡检、手动操作 |
| 维修班 | 3-5 | 设备维护、抢修 |
| 辐射防护 | 1-2 | 监测、去污 |

### 属性

每人有：
- **技能等级**（1-5）：影响操作速度、失误率
- **疲劳**（0-100）：连续工作上升，休息下降。高疲劳 → 失误率飙升
- **士气**（0-100）：影响主动性和报告意愿。低士气 → 隐瞒异常
- **辐射剂量**（累积）：超标 → 强制离岗

### 班次与疲劳

- 正常班次8小时，疲劳+20
- 加班：可强制留人，疲劳+40，士气-10
- 休息：交班后疲劳自然恢复
- 人手不足时被迫加班 → 恶性循环

### 培训

- 花钱送人培训 → 技能+1（需要时间，期间少一个人）
- 事故后强制培训 → 免费但士气下降

### 事故追责

- 严重事故后：上级调查
- 可能结果：警告 / 扣薪 / 撤换人员 / 玩家被撤职（游戏结束）
- 玩家可甩锅给下属（短期有效，长期士气崩溃）

## 政治与监管

### 权力链

```
玩家（值班班长）
  ↑
站长
  ↑
上级主管部门（能源部/公司总部）
  ↑
国家核安全监管机构
```

### 压力来源

| 来源 | 要求 | 不满足的后果 |
|------|------|-------------|
| 站长 | 发电指标、可用率 | 警告 → 撤职 |
| 主管部门 | 利润、上缴 | 削减预算 → 恶性循环 |
| 监管机构 | 安全合规、报告 | 罚款 → 停堆整顿 → 吊销执照 |

### 指标系统

- 发电计划：月度下达，完成率影响评价
- 安全指标：SCRAM次数、辐射泄漏、人员剂量
- 经济指标：利润率、成本/度电

指标互相矛盾：要发电就要压安全裕度，要安全就完不成发电计划。这是核心张力。

### 检查事件

- 随机触发监管检查
- 检查期间必须配合（降功率或停堆）
- 发现问题 → 整改要求 + 期限
- 逾期未改 → 升级处罚

## 事件系统

### 事件分类

| 类别 | 示例 | 频率 |
|------|------|------|
| 设备故障 | 泵泄漏、阀门卡涩、仪表失灵 | 高（每周1-3次） |
| 外部事件 | 电网波动、极端天气、地震 | 中（每月1-2次） |
| 人为事件 | 操作失误、巡检遗漏 | 取决于人员状态 |
| 监管事件 | 检查、新法规、许可证到期 | 低（每季度） |
| 政治事件 | 领导视察、媒体关注、预算变动 | 低（随机） |
| 级联事件 | 小故障 → 未处理 → 大事故 | 取决于玩家响应 |

### 严重度曲线

| 阶段 | 特征 |
|------|------|
| 前期（第1-3月） | 小故障为主，教学期 |
| 中期（第4-12月） | 中等事件增多，设备开始老化 |
| 后期（第12月+） | 故障频率上升，大修压力，经济紧张 |

不维护 → 指数恶化 → 必然事故

### 事件生成规则

```
事件概率 = 基础概率 × 设备老化系数 × 人员失误系数 × 维护质量系数
维护好 → 系数低 → 事件少
维护差 → 系数高 → 事件多 → 更多维修支出 → 恶性循环
```

### 玩家响应

事件发生时：
- 警报触发，时间自动降为1x
- 显示事件描述 + 可用选项
- 选项有延迟（取决于人员技能和距离）
- 不响应 → 事件自动升级
- 响应后 → 结果判定（成功/部分成功/失败）

---

## 失败条件

| 条件 | 触发 | 结局 |
|------|------|------|
| 堆芯熔毁 | 反应堆失控 | 最严重，游戏结束 |
| 玩家被撤职 | 指标连续不达标 / 重大事故追责 | 游戏结束 |
| 电站破产 | 连续6月亏损 | 游戏结束 |
| 执照吊销 | 安全违规累积 | 游戏结束 |

没有"胜利"。目标是活得久、赚得多、安全记录好。

---

## 评分（无尽模式）

游戏结束时计算综合评分：

```
总分 = 运行天数 × 10
     + 总发电量(GWh) × 5
     + 安全记录分（无事故天数 × 2 - SCRAM次数 × 50）
     + 经济分（累计利润 / 1000）
     - 人员事故（辐射超剂量人数 × 100）
```

排行榜按总分排序。
