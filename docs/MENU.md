# 主菜单设计文档

## 设计定位

主菜单不是"游戏菜单"，是值班室交接班。

玩家打开游戏的体验 = 一名操纵员走进控制室，打开面板电源，开始值班。所有交互元素都从"控制面板"的隐喻出发，不用任何通用游戏 UI 语言（没有渐变按钮、没有卡片式布局、没有圆角阴影）。

一句话原则：如果切尔诺贝利 4 号机组的操纵员看到你的菜单，他应该觉得这是他的工作台。

## 启动序列（Boot Sequence）

游戏启动后不直接显示菜单，先播放一段 3–5 秒的面板通电动画：

| 时间 | 画面 | 音效 |
|------|------|------|
| 0.0s | 全黑 | 寂静 |
| 0.3s | 屏幕中央出现一行绿色磷光文字：РБМК-1000 СИСТЕМА УПРАВЛЕНИЯ | 继电器吸合声（咔嗒） |
| 0.8s | 文字下方逐行打出：ИНИЦИАЛИЗАЦИЯ... ПРОВЕРКА ДАТЧИКОВ... ГОТОВО | 打字机节奏，每行一声短促电子音 |
| 1.5s | 背景从黑色渐变为深灰绿色（控制面板底色），面板纹理淡入 | 低频变压器嗡鸣声渐入（50Hz 基频） |
| 2.5s | 指示灯从左到右依次亮起（绿→绿→绿→琥珀→绿） | 每盏灯一声轻响 |
| 3.0s | 菜单项以"拨动开关"动画逐个翻出 | 机械开关声 × N |
| 3.5s | 就绪。光标停在第一项。 | 嗡鸣声稳定持续 |

跳过机制：任意按键 / 点击跳过整个序列，直接显示菜单。首次启动不可跳过（建立第一印象），之后可跳过。

## 菜单结构

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│   РБМК-1000 · БЛОК №4                                  │
│   ─────────────────────────────────────                 │
│                                                         │
│   [▣] НАЧАТЬ СМЕНУ          开始值班（新游戏）           │
│   [▣] ПРОДОЛЖИТЬ            继续值班（读档）             │
│   [▣] СЦЕНАРИИ              场景选择                    │
│   [▣] ДОКУМЕНТАЦИЯ          操作规程（手册）             │
│   [▣] НАСТРОЙКИ             设置                       │
│   [▣] ВЫХОД                 退出                       │
│                                                         │
│   ─────────────────────────────────────                 │
│   СМЕНА: ---  |  МОЩНОСТЬ: 0 МВт  |  t: 00:00:00      │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 各菜单项定义

| 序号 | 俄文标签 | 中文功能 | 行为 |
|------|----------|----------|------|
| 1 | НАЧАТЬ СМЕНУ | 新游戏 | → 进入"值班配置"子菜单（选机组、难度、起始工况） |
| 2 | ПРОДОЛЖИТЬ | 继续 | → 读取最近存档。无存档时此项灰显（指示灯灭） |
| 3 | СЦЕНАРИИ | 场景 | → 场景列表（切尔诺贝利 1986、正常运行、氙振荡等） |
| 4 | ДОКУМЕНТАЦИЯ | 手册 | → 打开游戏内操作规程（RBMK 操作手册精简版） |
| 5 | НАСТРОЙКИ | 设置 | → 音量、语言、画质、按键映射 |
| 6 | ВЫХОД | 退出 | → 确认对话框："ПОКИНУТЬ СМЕНУ?"（离开值班？） |

### 底部状态栏

始终显示，模拟控制面板底部的数字显示条：

- **СМЕНА（班次）**：无存档时显示 `---`，有存档显示班次编号
- **МОЩНОСТЬ（功率）**：无存档时 `0 МВт`，有存档显示存档时的热功率
- **t（时钟）**：实时走动的值班时钟（纯装饰，从 00:00:00 开始计）

## 视觉规范

### 色彩

| 用途 | 色值 | 说明 |
|------|------|------|
| 面板底色 | `#2B2E2A` | 深灰绿，苏联工业设备涂装 |
| 面板边框/分割线 | `#4A4E48` | 略亮的金属灰 |
| 主文字（标签） | `#C8CFC0` | 磷光灰白 |
| 高亮/选中 | `#7FFF7F` | CRT 磷光绿 |
| 警告/不可用 | `#FFB347` | 琥珀色（指示灯未亮） |
| 危险/退出确认 | `#FF4444` | 红色（仅用于 AZ-5 相关和退出确认） |
| 背景暗纹 | `#1E211D` | 面板金属拉丝纹理底色 |

### 字体

| 层级 | 字体 | 备注 |
|------|------|------|
| 标题 | PT Mono Bold 或 Share Tech Mono | 等宽，模拟打字机/终端 |
| 菜单项 | PT Sans / Roboto Condensed | 紧凑无衬线，模拟面板丝印 |
| 数字显示 | DS-Digital 或 Seven Segment | 七段数码管风格 |
| 俄文标签 | 同上，需支持 Cyrillic | — |

### 指示灯系统

每个菜单项左侧有一盏圆形指示灯（直径 12px）：

| 状态 | 表现 |
|------|------|
| 可用 | 绿色常亮，微弱辉光（box-shadow: 0 0 6px #7FFF7F） |
| 选中/悬停 | 绿色亮度提升 + 轻微闪烁（2Hz） |
| 不可用 | 琥珀色常亮（如"继续"无存档时） |
| 危险操作 | 红色（仅退出确认弹出时） |

### 面板纹理

背景叠加一层 SVG 噪声纹理（金属拉丝效果），opacity 0.03。面板区域有 2px 内凹边框（inset shadow），模拟实体面板的厚度感。

## 交互设计

### 导航方式

| 输入 | 行为 |
|------|------|
| ↑ / ↓ 或 W / S | 移动选中项 |
| Enter / 左键点击 | 确认 |
| Esc | 返回上一级 / 取消 |
| 鼠标悬停 | 选中该项（指示灯闪烁） |

### 选中反馈

- 选中项文字颜色从 `#C8CFC0` → `#7FFF7F`
- 左侧指示灯亮度提升
- 播放一声短促电子音（频率 880Hz，时长 30ms，方波）
- 文字左侧出现 ▶ 光标（模拟终端光标）

### 确认反馈

- 指示灯快闪 3 次（100ms 间隔）
- 播放继电器动作声
- 面板整体做一次微弱的"震动"（translateY: 1px，持续 50ms）——模拟按下实体按钮的触感

### 退出确认

选择 ВЫХОД 后，不直接退出。面板底部弹出一行红色文字：

```
ПОКИНУТЬ СМЕНУ? [ДА] [НЕТ]
```

选 ДА → 屏幕渐暗 → 关闭。选 НЕТ → 返回菜单。

## 音效设计

| 事件 | 音效描述 | 实现建议 |
|------|----------|----------|
| 环境底噪 | 50Hz 变压器嗡鸣 + 远处冷却泵低频震动 | 循环播放，音量 -20dB |
| 菜单项切换 | 短促方波 beep（880Hz, 30ms） | Web Audio API 合成 |
| 确认选择 | 继电器吸合声（机械咔嗒） | 预录采样 |
| 面板通电 | 电流渐强 + 继电器组依次动作 | 预录采样，2s |
| 指示灯亮起 | 极轻的"叮"（2000Hz, 15ms, 正弦波） | 合成 |
| 退出确认 | 低频警告音（220Hz, 200ms） | 合成 |

音量原则：所有 UI 音效不超过环境底噪 +10dB。菜单是安静的控制室，不是街机。

## 子菜单：值班配置（НАЧАТЬ СМЕНУ）

选择"开始值班"后进入：

```
┌─────────────────────────────────────────┐
│  КОНФИГУРАЦИЯ СМЕНЫ                     │
│  ─────────────────────────────────────  │
│                                         │
│  БЛОК (机组):    [№1] [№2] [№3] [№4]  │
│                                         │
│  РЕЖИМ (模式):   ○ ШТАТНЫЙ (正常运行)   │
│                  ○ ПЕРЕХОДНЫЙ (过渡工况) │
│                  ○ АВАРИЙНЫЙ (事故工况)  │
│                                         │
│  СЛОЖНОСТЬ (难度): [▁▂▃▅▇]             │
│                                         │
│  ─────────────────────────────────────  │
│  [▣] НАЧАТЬ  →  开始值班               │
└─────────────────────────────────────────┘
```

| 参数 | 选项 | 影响 |
|------|------|------|
| 机组 | №1–№4 | 纯装饰 + 初始设备老化程度不同 |
| 模式 | 正常 / 过渡 / 事故 | 初始功率、氙浓度、可用系统 |
| 难度 | 5 档滑块 | 保护系统灵敏度、事件频率、容错时间 |

## 状态机

```
[BOOT] ──3.5s──→ [MENU_MAIN]
                      │
        ┌─────────────┼─────────────┬──────────────┐
        ▼             ▼             ▼              ▼
  [CONFIG]      [SCENARIOS]    [SETTINGS]    [CONFIRM_EXIT]
        │             │             │              │
        ▼             ▼             ▼              ▼
   [GAME]        [GAME]       [MENU_MAIN]    [SHUTDOWN]
```

- 任何子菜单按 Esc → 返回 MENU_MAIN
- SHUTDOWN：屏幕渐暗 1s → 关闭进程 / 关闭标签页

## 平台差异

| 项目 | Web | Love2D |
|------|-----|--------|
| 分辨率 | 响应式，最小 1024×768 | 固定 1280×720，可全屏 |
| 字体加载 | Google Fonts / 本地 woff2 | assets/fonts/ 下 .ttf |
| 音效 | Web Audio API 实时合成 | love.audio + .ogg 采样 |
| 面板纹理 | CSS background + SVG noise | Shader 或预渲染 PNG |
| 存档 | localStorage | love.filesystem |
| 退出 | 关闭标签页（无法拦截则显示"可关闭"） | love.event.quit() |

## 文件映射

| 菜单功能 | Web 实现 | Love2D 实现 |
|----------|----------|-------------|
| 主菜单 UI | web/js/menu.js | love/src/menu.lua |
| 启动动画 | web/js/boot.js | love/src/boot.lua |
| 音效引擎 | web/js/audio.js | love/src/audio.lua |
| 场景数据 | tests/scenarios/*.json（共用） | 同左 |

## 验收标准

- [ ] 首次启动必须播放完整 boot 序列
- [ ] 所有菜单项有指示灯状态反馈
- [ ] 无存档时"继续"项灰显且不可点击
- [ ] 退出必须二次确认
- [ ] 环境底噪在菜单全程持续播放
- [ ] 键盘和鼠标均可完整操作
- [ ] 场景列表从 JSON 动态加载，不硬编码
- [ ] Web 端 1024×768 下无溢出
- [ ] Love2D 端 720p 全屏无拉伸变形
