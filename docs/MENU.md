## 1 · 设计原点

主菜单不是"开始 / 设置 / 退出"三行字。

它是一台被批准投入教学使用的训练台的控制屏。你坐到它面前，不是"启动一个游戏"，而是接班——上一班走了，控制台还温着，CRT 还亮着，你登录、确认工况、选择今天要进哪种值班。

内部代号：**ЭКРАН ВЫБОРА СМЕНЫ / 班次选择屏**。

所有视觉、交互、命名都从这一句长出来。

---

## 2 · 屏幕结构：四区仪表盘

不是居中一摞按钮。是分区仪表盘——左边你动手，右边它回话，上下是铭牌和状态。

```
┌─●──────────────────────────────────────────────────────────●─┐
│  ┌────────────────────────────────────────────────────────┐  │
│  │ ① 顶栏：标识 + 状态灯 + 时钟                           │  │
│  ├─────────────────────────────┬──────────────────────────┤  │
│  │                             │                          │  │
│  │ ② 左栏：操作区              │ ③ 右栏：反馈区           │  │
│  │    （你动手）               │    （它回话）            │  │
│  │                             │                          │  │
│  ├─────────────────────────────┴──────────────────────────┤  │
│  │ ④ 底栏：版本铭牌 + 操作提示                            │  │
│  └────────────────────────────────────────────────────────┘  │
 └─●──────────────────────────────────────────────────────────●─┘
```

| 区 | 内容 | 设计意图 |
|----|------|----------|
| ① 顶栏 | 系统名 «ЩИТ» + 三盏状态灯（ПУСК / ГОТОВ / АВАР）+ 时钟 | 一上来就告诉你"这台机器活着"，灯和钟是环境心跳 |
| ② 左栏 | 操作项（见 §3） | 主操作区，纵向排列，像控制台选择键 |
| ③ 右栏 | 反馈区（见 §4） | 核心反馈机制——你动，它变，不让你猜 |
| ④ 底栏 | 版本三层（接通 version.json）+ 键位提示 ↑↓ ⏎ Esc | 版本不硬编码；键位永远可见，因为是键盘机器 |

四角 ● = 铆钉。外框 = 拉丝铝。内框 = CRT 屏体（带暗角、扫描线）。

## 3 · 左栏：操作区

### 3.1 常态布局

```
│   ┌──────────────┐  │
│   │ ▶ 开始游戏    │  │  ← 大按钮，主焦点
│   └──────────────┘  │
│                     │
│     存档            │  ← 小字，不常点
│     设置            │
│     退出            │
```

| 项 | 俄文 | 直白中文 | 说明 |
|----|------|----------|------|
| 开始游戏 | ПУСК | 启动 / 开始 | 唯一大按钮。按下后右栏通电，弹出模式子屏（见 §4） |
| 存档 | АРХИВ | 存档 / 读档 | 继续上次值班、读档、删档。v0.6 存档系统就绪后激活，之前灰掉盖章 |
| 设置 | НАСТРОЙКИ | 整定 / 设置 | 进入设置屏（见 §5） |
| 退出 | ВЫХОД | 退班 / 退出 | 关屏，走人。按后弹确认："确认退班？" |

### 3.2 焦点规则

- 进入主菜单时，焦点默认在「开始游戏」大按钮上（▶ 标记）
- ↑↓ 在四个操作项之间移动
- 当右栏子屏通电时（见 §4），焦点跳入子屏，左栏按钮标记从 ▶ 变为 ●（已激活/通电中）
- Esc 关闭子屏，焦点跳回左栏按钮，● 恢复为 ▶

## 4 · 右栏：反馈区（核心交互）

### 4.1 设计原则

右栏是这屏唯一不无聊的地方。它不是装饰，是反馈机制：你动，它变。

右栏有两种状态：**待命（暗屏）** 和 **通电（子屏激活）**。

### 4.2 状态 A：待命（未按开始）

右栏是一块没通电的暗屏，只有虚线框和一句待命语。

```
│  ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄  │
│  ┄  子屏待命    ┄  │
│  ┄              ┄  │
│  ┄ 选择工况以启动  ┄│
│  ┄              ┄  │
│  ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄  │
```

虚线框 = 未通电的玻璃，暗的。
待命语："选择工况以启动" / "ВЫБЕРИТЕ РЕЖИМ ДЛЯ ЗАПУСКА"。
不空着，空着右边就死了。

### 4.3 状态 B：通电（按下开始后）

按下「开始游戏」（⏎），右栏通电展开：

动效：从一条水平亮线扩成面板（CRT 通电感），伴随继电器"咔"一声。扫描线从上到下扫一遍。
内容：模式列表浮出。

```
│  ╔═ 选择工况 ════╗  │
│  ║ ▸ 自由操作     ║  │
│  ║   历史重演     ║  │
│  ║   挑战模式     ║  │
│  ╠════════════════╣  │
│  ║ 回车进 / Esc 关 ║  │
│  ╚════════════════╝  │
```

### 4.4 模式列表

| 编号 | 俄文 | 直白中文 | 说明 | 标签 |
|------|------|----------|------|------|
| 01 | СМЕНА | 自由操作 | 沙盒。控制台全归你，想开堆开堆，想停堆停堆，没任务、不计时 | [свобод.] |
| 02 | ХРОНИКА | 历史重演 | 切尔诺贝利等历史剧本，按真实事件线走 | [сюжет] |
| 03 | ВЫЗОВ | 挑战模式 | 限时 / 随机故障，考你反应 | [лимит] |

未解锁项处理：不删掉，灰掉 + 盖红章 НЕ ДОПУЩЕНО / 未授权。选中它按 ⏎ → 不进入，红章抖动 + 拒绝音"嗡—"。空位也是叙事：你能看见"还有班没开放给你"。

### 4.5 子屏内操作

| 按键 | 行为 |
|------|------|
| ↑↓ | 在模式间移动，▸ 跳行，该行磷光增强 |
| ⏎ | 进入选中模式（屏幕收成亮线再展开，进场景） |
| Esc | 关闭子屏，退回待命态（§4.2），焦点回左栏 |
| 1 / 2 / 3 | 数字键直选对应模式（老控制台快捷键手感） |

### 4.6 右栏在其他左栏项时的行为

| 左栏焦点 | 右栏显示 |
|----------|----------|
| 开始游戏（未按） | 待命暗屏（§4.2） |
| 开始游戏（已按） | 通电子屏（§4.3） |
| 存档 | 存档简报卡（v0.6 后激活；之前显示"АРХИВ НЕ ДОСТУПЕН / 档案系统未就绪"） |
| 设置 | 设置预览："整定参数 · 6 个分区"（或直接跳转设置屏，见 §5） |
| 退出 | 确认卡："确认退班？ ⏎ 是 / Esc 否" |

## 5 · 设置屏（整定 / НАСТРОЙКИ）

### 5.1 结构

设置屏复用主菜单的双栏逻辑：左边选分区，右边调旋钮。你已经懂主菜单那套"左选右看"，所以设置零学习成本。

```
┌──────────────────────────────────────────┐
│  整定 / 设置                              │
├─────────────────────┬────────────────────┤
│  ▸ 声音             │  主音量       ▮▮▮▮▯ │
│    画面             │  控制室底噪   ▮▮▮▯▯ │
│    操作             │  警报音量     ▮▮▯▯▯ │
│    工况 / 难度      │  广播语音     ▮▮▮▮▯ │
│    界面 / 语言      │  [ ] 一键静音       │
│    系统 / 关于      │                    │
├─────────────────────┴────────────────────┤
│  恢复出厂整定                Esc 返回主菜单 │
└──────────────────────────────────────────┘
```

### 5.2 六个分区

| 分区 | 俄文 | 包含内容 |
|------|------|----------|
| 声音 | ЗВУК | 主音量、控制室底噪、警报音量、广播语音、一键静音 |
| 画面 | ЭКРАН | CRT 显像管强度、全屏/窗口、分辨率、亮度、垂直同步 |
| 操作 | УПРАВЛЕНИЕ | 键位绑定、鼠标灵敏度、手柄支持（若有） |
| 工况 / 难度 | РЕЖИМ | 仪表数字辅助、故障预警等级、后果模式、时间加速（自由模式） |
| 界面 / 语言 | ИНТЕРФЕЙС | 语言（中/俄/英）、字幕/广播文本开关、环境动效强度、色盲/高对比模式 |
| 系统 / 关于 | СИСТЕМА | 清除存档、重置设置到出厂、版本号三层（接通 version.json）、制作信息 |

### 5.3 五个"灵魂旋钮"

| 分区 | 旋钮 | 干嘛的 | 为什么是灵魂 |
|------|------|--------|-------------|
| 画面 | CRT 显像管强度 | 滑块 0–100。0 = 干净液晶屏，100 = 老破显像管（扫描线/磷光/暗角/雪花全拉满） | 这游戏的"长相"就靠它，必须能让玩家自己拧 |
| 声音 | 控制室底噪 | 单独调"嗡鸣 + 继电器 + 盖革计数咔咔"的环境声 | 氛围全靠它，但有人嫌吵，得能关 |
| 工况 | 仪表数字辅助 | 开 = 指针值直接读成数字（教学）；关 = 只看指针（硬核） | 一个开关分出两种玩家 |
| 工况 | 故障预警等级 | 出事前提前闪灯提示 vs 完全不提示、自己看仪表判断 | 教学辅助的总闸 |
| 工况 | 后果模式 | 写实（一次失误堆就毁）vs 宽容（给提示、能挽回） | "难度"的本质，比"简单/普通/困难"三个词准确得多 |

### 5.4 底栏

左：恢复出厂整定（= 恢复默认设置）。按后弹确认。
右：Esc 返回主菜单。

## 6 · 视觉规格

### 6.1 背景分层（不是一块黑）

| 层 | 内容 | 说明 |
|----|------|------|
| 最底 | 控制室暗环境 | 带细噪点的沥青墨绿，不是 #000 纯黑 |
| 中层 | CRT 屏体 | 带弧度暗角、扫描线、磷光余晖、极淡雪花 |
| 上层 | 内容文字 | 琥珀/绿/红三色文字和图形 |

三层叠起来，屏是"嵌在环境里的一块发光玻璃"，不是"黑网页上的绿字"。

### 6.2 配色：三色语义体系

| 角色 | 色 | 用在哪 | 语义 |
|------|-----|--------|------|
| 主磷光 | 琥珀 / 暖橙 | 正文、选中项、标题 | 老示波器/报警屏的暖光，做主色比绿少见、更"作品" |
| 正常指示 | 冷绿 | 状态灯 ГОТОВ、ДОСТУПНО、正常数值 | "一切正常" |
| 警告 / 印章 | 警示红 | АВАР 灯、未授权章、锁定项、拒绝反馈 | 只在该响的时候响 |

颜色本身在说话，不是装饰。这就和"单一酸绿"拉开了距离。

### 6.3 字体：两族配对

| 用途 | 字体 | 为什么 |
|------|------|--------|
| 展示大字（标题、编号、版本号） | Oswald（condensed 无衬线，含西里尔） | 压缩字形像铝牌上的冲压字，工业标牌味 |
| 屏内正文 / 等宽数据 | IBM Plex Mono（含西里尔，tabular 数字） | 控制台读数的等宽感，数字对齐不跳 |
| 中文注释 | Noto Sans SC | 西里尔族不带中文，中文单独配，干净 |

强对比靠字号 + 字重 + 字距。

### 6.4 边框

屏外那圈不是 1px border，是拉丝铝 + 四角铆钉 + 蚀刻铭牌。版本号就蚀刻在底栏那块铝上，像出厂牌。

## 7 · 交互与微动效

### 7.1 操作反馈表

| 你的动作 | 屏幕反应 | 声音 |
|----------|----------|------|
| ↑↓ 或鼠标移到新项 | 左栏 ▸ 跳行、该行磷光增强、编号灯亮；右栏内容 crossfade 切换 | 一声轻继电器"咔" |
| 悬停/聚焦 | 扫描线瞬时微加速，或屏极轻地抖一下 | 可选：电流细响 |
| ⏎ 确认进入 | 整屏收成一条水平亮线再展开（CRT 切信号过渡），然后进场景 | 继电器连响 / 盖章声 |
| 选中"未授权"项按 ⏎ | 不进入；红章 НЕ ДОПУЩЕНО 抖动 | 低沉拒绝音"嗡—" |
| 数字键 1–3 | 子屏内直选对应模式 | 同移动音 |
| Esc | 子屏开着 = 关子屏回待命；退出项上 = 确认退班 | 轻咔 |

### 7.2 环境层

| 元素 | 行为 | 频率 |
|------|------|------|
| 顶栏 ГОТОВ 绿灯 | 缓慢呼吸（亮度 60%↔100%） | 持续，周期 ~3s |
| 时钟秒位 | 正常走 | 每秒 |
| 某处电压/频率读数 | 末位数字不停跳（像真仪表抖动） | 持续，~200ms 一跳 |
| 整屏雪花 | 极稀疏掠过 | ~30–60s 一次 |

**克制原则**：动效是"机器在呼吸"，不是"网页在炫技"。环境动效强度可在设置 → 界面/语言分区调节（§5.2）。

## 8 · 键盘 / 鼠标控制方案

| 输入 | 行为 |
|------|------|
| ↑ / ↓ | 在操作项 / 模式间移动 |
| ⏎ / Enter | 确认 / 进入 |
| Esc | 返回 / 关闭子屏 / 取消 |
| 1 / 2 / 3 | 子屏内直选模式 |
| 鼠标点击 | 等效于移动到该项 + ⏎ |
| 鼠标滚轮 | 等效于 ↑↓（可选） |

全键盘可操作是硬性要求。这是模拟器，不是网页。

## 9 · 入场衔接（占位，不展开）

主菜单不是第一帧。开机顺序：

```
冷屏 → 开机自检滚屏 → 档案章 «ДОПУЩЕНО» 盖下 → 落到本屏（班次选择）
```

盖章动画和自检滚屏属于 v0.2 的另一个子任务，另立文档（ЩИТ-DOC-BOOT-01），此处只占位。
