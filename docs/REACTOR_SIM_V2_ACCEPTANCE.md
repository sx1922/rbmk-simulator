## 验收总则

### 0.1 通过条件

| 级别 | 含义 | 要求 |
|------|------|------|
| P0 阻断 | 不通过则不可合入 | 100% 通过 |
| P1 严重 | 不通过需书面豁免 | ≥ 95% 通过 |
| P2 一般 | 记录为已知问题 | ≥ 90% 通过 |

### 0.2 测试环境

| 项目 | 要求 |
|------|------|
| 运行时 | 浏览器 Chrome 120+ / Firefox 120+ / Safari 17+ |
| 帧率 | 60 fps（dt = 16.67 ms） |
| 仿真步长 | 固定 dt = 0.1 s（逻辑步），渲染插值 |
| 浮点精度 | IEEE 754 double（JS 默认） |
| 随机种子 | 可固定（用于回归测试） |

### 0.3 回归基线

所有 V1.0 的验证用例（REACTOR_SIM.md §验证）必须在 V2 代码上原样通过，偏差 ≤ 0.01%。

这是最高优先级。V2 是增量，不是重构。如果 V1 用例失败，说明 V2 破坏了已有逻辑，必须回退。
