# 值班日志模板 — Оперативный Журнал

## 格式

```
═════ ОПЕРАТИВНЫЙ ЖУРНАЛ · 26.04.1986 ═════
Operator: [签名]

[时间] "[操作/事件描述]"
[时间] "[操作/事件描述]"
...

══════════════════════════════════════════
```

## 标准条目

### 交接班
```
06:00 — Смена А приняла блок №4. Мощность 100%. Параметры в норме.
14:00 — Смена Б приняла блок №4. Мощность 100%. Плановое снижение.
22:00 — Смена В приняла блок №4. Мощность 50%. Подготовка к испытанию.
```

### 功率变更
```
HH:MM — Снижение мощности: [причина]. Начало: XX%. Цель: YY%. Темп: Z%/мин.
HH:MM — Мощность стабилизирована на XX%. OPR: YY стержней.
HH:MM — Подъём мощности: [причина]. Текущий период: T=YY с.
```

### 异常事件
```
HH:MM — [Обнаружено/Произошло]: [описание]. Принятые меры: [действия].
HH:MM — Отключился ГЦН №N. Включён резервный. Мощность: XX%.
HH:MM — Срабатывание АЗ-5 по каналу ПN ([причина]).
```

### 保护旁通
```
HH:MM — Отключена защита ПN по распоряжению [кто]. Причина: [обоснование].
HH:MM — Защита ПN восстановлена. Время отключения: YY мин.
```

### 试验记录
```
HH:MM — Начало испытания: [название]. OPR до: XX. Мощность: YY%.
HH:MM — Отключена защита ПN, ПM.
HH:MM — АЗ-5 нажат. Время: HH:MM:SS.
HH:MM — [Результат / отклонение / аварийная ситуация]
```
