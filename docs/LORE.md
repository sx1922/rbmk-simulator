## 1 · 世界观背景

游戏设定于 **1986 年 4 月 25—26 日，切尔诺贝利核电站（ЧЕРНОБЫЛЬСКАЯ АЭС）4 号机组**。

- 电站铭牌：`ЧЕРНОБЫЛЬСКАЯ АЭС ИМ. В.И. ЛЕНИНА`（列宁切尔诺贝利核电站）
- 机组编号：4 号（блок №4）
- 反应堆型号：**РБМК-1000**（大功率压力管式反应堆，石墨慢化、轻水冷却沸水堆）
- 额定热功率 3200 МВт，电功率 1000 МВт
- 工艺管（ТК）1661 根，控制棒 211 根
- 冷却剂在管内沸腾，蒸汽直接送汽轮机；无整体压力容器
- 关键设计缺陷：**正空泡系数 + 低功率下端部效应（石墨置换体）** → 低 ORM 工况下停堆瞬间引入正反应性

## 7 · 机制设定（本轮新增）

### 7.1 点火启动（ПУСК）

每次开始班次（任意模式）播放点火动画：

- 全屏黑底 → 堆芯核心由暗转亮（蓝白光核）
- 两圈冲击环扩散
- 字幕：`ПУСК` + 「点火 · 反应堆临界」
- 2.6 秒后淡出进入值班

### 7.2 熔毁爆炸演出（MELTDOWN FX）

`S.meltdown` 触发时（z-index 830，压过终局白闪 800）：

1. 全屏白闪（0.5s）
2. 黑色核电站剪影从底部升起（厂房 + 烟囱 + 反应堆厂房，0.4s）
3. 反应堆厂房位置爆发火球 ×2 + 碎片 ×3
4. 0.5s 后剪影整体炸飞（上移消散），屋顶与烟囱单独抛出（旋转）
5. 黑烟升腾，2s 后淡出进入终局结算

### 7.3 挑战模式事件

| 事件 | 处理 |
|------|------|
| steam_leak 蒸汽泄漏 | 立即抢修（停机 60s，功率压至 3%）/ 稍等（默认抢修）；面板弹出暂停模拟 |
| dispatch 甩负荷 | 调度电话，设定目标功率 |
| pump_trip 泵跳闸 | 限时恢复泵 |
| period_warn / orm_drain | 报警提示 |
| phone | 调度电话 12s 应答 |

## 8 · 物理模型速览

见 `docs/REACTOR_SIM.md`（完整规格）。实现要点（engine.js）：

- 半隐式点堆方程（ρ-β 型），显式欧拉不再使用
- 反应性合成：控制棒 + 空泡（+0.0009 系数）+ 氙毒（+0.004）+ 端部效应（提棒/停堆正端）
- AZ-5 后调节器冻结、rodTarget 归零
- 保护定值：П2 周期 < 10 s 紧急停堆；ORM 低限报警
