# Changelog

## [0.1.0] - 2026-07-30

### 新增
- 项目初始化，完整目录结构
- 物理引擎：中子动力学、反应性合成、热工水力(5区)、氙毒、汽轮机、AZ-5、保护逻辑
- 游戏系统：经济、信任、人员、维护、随机事件、安全试验任务链
- UI 层：仪表盘、面板、弹窗、趋势图
- 验证测试：4 个单元测试 + 3 个场景 JSON

### 版本号系统
- 制定三层版本号规范（语义版本 · 构建日期 · 修订代号），文档见 design.md
- 统一项目名称为「ЩИТ」
- 规划 v0.1 ~ v1.0 版本轨迹与代号
- 制定跨平台版本同步规则（Web / LÖVE 同号异平台）

### Web 版本 (`rbmk-sim/`)
- 独立 HTML/CSS/JS 控制室仿真器，纯前端无后端依赖
- 物理引擎：点堆动力学 + 单组缓发中子 + 空泡反馈 + 氙/碘模型 + 棒端效应 + П1–П5 保护 + 熔毁
- 苏联控制室主题样式（拉丝铝面板、螺丝、指针表盘、AZ-5 按钮、报警灯）
- Canvas 渲染：仪表盘、堆芯轴向剖面、棒位条、反应性平衡、四线记录仪、挂钟
- 桌面道具系统：11 页运行规程手册（含修订通知/红黑条）、值班日志（可编辑导出）、MK-61 计算器（OPR/Xe 直读）、DP-5 剂量计（量程切换+Geiger 音效）、VCh 电话、茶炊
- 主循环 + UI 绑定：功率滑块、摇杆开关、泵按钮、AZ-5 透明盖 + 钥匙闭锁、事件日志、报警灯联动
- 版本信息单一来源（version.json），控制台输出 + 右下角戳记 + 关于面板覆盖
