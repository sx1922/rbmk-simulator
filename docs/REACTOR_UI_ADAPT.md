# REACTOR_UI_ADAPT.md — 控制台 UI 适配新物理引擎

文档编号：GDD-UI-ADAPT
版本：1.0.0
状态：草案
依赖：UI.md v1.0、UI_INTERACTION.md v1.0、REACTOR_SIM.md（含升级章节）
性质：本文档不是物理引擎文档。本文档定义游戏 UI 如何读取、显示、交互新物理引擎输出的状态量。物理方程本身不在本文档范围内。

## 适配原则

| 原则 | 说明 |
|------|------|
| 不改区域划分 | UI.md 的四区域（区域 1-4）结构不变 |
| 不改浮层状态机 | 电话、对话、日志、菜单浮层的状态机不变 |
| 只增不改 | 在已有区域内增加仪表/控件/指示灯，不移动已有元素 |
| 数据单向流 | 物理引擎 → 仪表中间层 → 渲染。UI 不写回物理状态 |
| 玩家操作 → 输入层 → 物理引擎 | UI 控件只产生指令，不直接修改 ReactorState |

## 1 数据流架构

### 1.1 总链路

```
ReactorState（物理引擎输出）
       │
       ▼
InstrumentLayer（仪表中间层）
  ├── 量程截断（§3）
  ├── 一阶滞后（§4）
  ├── 噪声叠加（§4）
  ├── 故障注入（§5）
  └── 输出：DisplayValue[]
       │
       ▼
RenderLayer（渲染层）
  ├── 表盘/指针
  ├── 数字读数
  ├── 报警灯
  ├── 自记笔
  └── 象限图
       │
       ▼
InputLayer（输入层）
  ├── 玩家操作 → 指令
  ├── 前置条件检查
  └── 写入 ReactorState 的控制字段
```


## 4 仪表动态响应 UI 表现

### 4.1 与渲染层指针动画的关系

仪表中间层与渲染层指针动画是**两套独立机制，串联工作**：

```
物理引擎真实值 → 量程截断 → 一阶滞后(τ) → 噪声叠加 → 故障注入
  → DisplayValue.value
  → 渲染层指针动画：angle += (target - angle) * 0.1（惯性平滑）
  → 屏幕显示
```

- 一阶滞后模拟仪表电气/机械响应时间（τ 参数）
- 渲染层指针动画模拟表针的物理惯性（纯视觉平滑，不影响数据）
- 两者叠加：玩家看到指针先滞后再平滑跟随，视觉上更真实

### 4.2 各仪表 τ 值与视觉表现

| 仪表 | τ | 视觉表现 |
|------|---|----------|
| 热功率表 | 0.5s | 指针平滑跟随，几乎无感 |
| 周期表 | 1.0s | 轻微滞后 |
| 出口水温 | 3.0s | 指针明显滞后于实际变化。玩家看到温度"慢慢爬" |
| 辐射剂量仪 | 5.0s | 非常慢。事故后 5 秒读数才开始动 |
| 分离器水位 | 1.5s | 轻微波动感 |
| 分离器压力 | 2.0s | 中度滞后 |
| 给水流量 | 1.0s | 快速跟随 |
| 给水温度 | 120s（物理模型本身） | 极慢。仪表端 τ=0 |
| ORM 指示 | 0.2s | 几乎实时 |
| 棒位指示 | 0.3s | 编码器，无噪声 |

### 4.3 噪声视觉

| 仪表 | 噪声幅度 | 视觉表现 |
|------|---------|----------|
| 功率表 | 0.3%FS | 指针极轻微抖动。正常。玩家不会注意 |
| 给水流量 | 0.5%FS | 指针可见微抖（泵脉动）。正常 |
| 辐射剂量仪 | 2.0%FS | 指针明显抖动。正常（统计涨落） |
| ORM | 0.1%FS | 几乎不动 |

### 4.4 故障视觉

| 故障 | 指针表现 | 附加视觉 |
|------|----------|----------|
| STUCK | 指针完全静止 | 无（玩家需自己发现） |
| DRIFT | 指针缓慢偏移 | 无 |
| PEGGED | 指针顶在满刻度，轻微颤抖 | 表玻璃上可加一道裂纹（难度 4） |
| JITTER | 指针大幅随机跳动 | 表壳轻微震动音效 |
| REVERSE | 指针反向运动 | 无（最阴险的故障） |
| DEAD | 指针在零位不动 | 表背光灭（如果是电子表） |

### 4.5 故障识别交互

| 操作 | 效果 |
|------|------|
| 点击故障仪表 | 弹出小浮层："轻拍仪表"。对 STUCK/DEAD 无效。对 JITTER 可能暂时减轻 |
| 对比冗余表 | 玩家自己看两个表。UI 不做自动对比提示（难度 3-4） |
| 难度 1-2 | 故障仪表边框闪橙光 + 文字"仪表异常" |
| 难度 3 | 无提示。玩家自己发现 |
| 难度 4 | 无提示 + 备用表也可能故障 |

### 5.3 灯状态机（渲染层实现）

```ts
type LampState = 'OFF' | 'FAST_BLINK' | 'ON' | 'SLOW_BLINK';

interface LampRender {
  id: string;
  state: LampState;
  color: string;        // 'red' | 'orange' | 'yellow' | 'white'
  blinkTimer: number;
  label: string;        // 灯下方刻字
}

// 状态转换（由物理事件驱动）
function onNewAlarm(lamp: LampRender): void {
  lamp.state = 'FAST_BLINK';  // 2Hz
}

function onKvit(): void {
  for (const lamp of allLamps) {
    if (lamp.state === 'FAST_BLINK') lamp.state = 'ON';
    if (lamp.state === 'SLOW_BLINK') lamp.state = 'OFF';
  }
  stopAlarmBell();
}

function onAlarmCleared(lamp: LampRender): void {
  if (lamp.state === 'ON') lamp.state = 'SLOW_BLINK';  // 0.5Hz
}
```

完整状态转换路径：`OFF → FAST_BLINK → ON → SLOW_BLINK → OFF`

### 5.4 警铃行为

| 条件 | 铃声 |
|------|------|
| 有 FAST_BLINK 灯 | 连续响（800Hz） |

## 7 自记笔（КСУ）渲染

### 7.1 位置

自记笔位于**区域 1**（反应堆控制面板），功率表右侧。与现有文档（REACTOR_SIM.md §6.5）一致，功率表本身有 3 个显示通道：主表（区域 1）、备用表（区域 3）、自记笔（区域 1）。自记笔作为独立的纸带记录仪，与主功率表并排布置。

### 7.2 外观

| 属性 | 值 |
|------|------|
| 尺寸 | 120px 宽 × 200px 高 |
| 外壳 | 金属灰色方盒，前面板有玻璃窗 |
| 纸带 | 白色，从上方卷入，下方卷出 |
| 笔 | 红色（功率）+ 黑色（周期），两根 |
| 标签 | "КСУ-120" |

### 7.3 渲染逻辑

```ts
function updateRecorder(displayValues: DisplayValue[], dt: number): void {
  const paperSpeed = 20 / 3600;  // 20mm/h → px/step
  const x = paperCanvas.width - 1;

  // 功率笔（红）
  const pNorm = displayValues['INST_POWER'].value / rangeMax;
  const yPower = paperCanvas.height * (1 - pNorm);
  ctx_red.fillRect(x, yPower, 1, 1);

  // 周期笔（黑）
  const tNorm = periodToNorm(displayValues['INST_PERIOD'].value);
  const yPeriod = paperCanvas.height * (1 - tNorm);
  ctx_black.fillRect(x, yPeriod, 1, 1);

  // 纸带左移
  paperCanvas.scroll(-paperSpeed * dt, 0);
}
```

### 7.4 特殊状态

| 状态 | 纸带表现 |
|------|----------|
| 正常 | 红色曲线平稳波动 |
| 功率飙升 | 红线急速上升 → 顶在上沿画直线 |
| 量程切换 | 红线垂直落到零 → 再爬升 |
| AZ-5 | 红线急降 → 缓慢衰减（衰变热） |
| 爆炸 | 红线打到上沿 → 一个墨点 → 纸带停（断电） |
| 仪表故障 | 记录的是故障值（STUCK = 直线，JITTER = 乱线） |

### 11.2 与功率表的关系

停堆后：
- 功率表（PRKE 裂变功率）→ 迅速归零
- 衰变热显示 → 从 224 缓慢降
- 两者之和 = 实际热功率（热工水力用的）
- 但功率表只显示裂变功率。衰变热是单独的小数字显示
- **玩家必须意识到：功率表到零 ≠ 没有热**
