# 交互设计 — Проектирование Взаимодействия

## 设计哲学

玩家面前是一块 12 米宽的真实 БЩУ 面板。不是一屏。是一个空间。

交互原则：
- 一切皆物理。按钮要按下去，旋钮要转，推杆要推。
- 一切皆可见。不隐藏控件。信息过载是特性。
- 一切皆有反馈。按了就有声音、有位移、有灯变。
- 辅助默认开。但辅助不是"游戏提示"，是"值班主任的指示"。
- 移动端不是"缩小版"。是"重新布局版"。

## 视角系统

### 默认模式：自由平移 + 缩放

- 面板是一个 12m × 3m 的画布
- 鼠标拖拽空白处 = 平移
- 滚轮 = 缩放（0.5× – 3×）
- 双击 = 聚焦到该区域（自动平移+缩放到合适比例）
- ESC 或双击空白 = 回到全景（0.5×，看全貌）

缩放语义：

| 倍率 | 视野 | 可操作 |
|------|------|--------|
| 0.5× | 全景，看清分区布局 | 控件太小不能操作 |
| 1.0× | 标准，看清一个分区（~2m 宽） | 可操作 |
| 2.0× | 特写，看清一组控件（~0.5m 宽） | 读仪表 |
| 3.0× | 微距，读单个仪表的刻度 | — |

### 可选模式：第一人称

- 设置里开启（默认关）
- 鼠标移到屏幕边缘 = 转头
- 视角高度固定（站在面板前 1.5m）
- 不能平移。只能转头。
- 缩放 = 走近/后退（W/S 或滚轮）
- 这个模式下，屏幕边缘有轻微的"头部晃动"（sin 波，振幅 2px），模拟站立的微动。可关闭。

为什么默认关：第一人称更有压力，但操作效率低。玩家自己选。

### 模式切换

- 快捷键 V 切换
- 切换时相机平滑过渡（300ms）
- 第一人称模式下，平移操作自动映射为转头

### 各区域内容

**区域 1 — 反应堆控制（主操作区）**
- 控制棒操作：自动/手动模式切换（钥匙）、棒组选择（24 组，每组一个旋钮）、棒速设定（旋钮）、手动单棒操作（简化为组操作 + 关键单棒）
- ГЦН（主循环泵）：8 台泵，每台启动/停止按钮、运行灯、电流表
- 功率显示：热功率表（МВт）、中子功率表（%）、功率记录仪（自记笔，画曲线）

**区域 2 — 反应堆保护**
- АЗ-5 按钮（大红蘑菇头，带保护罩）
- 保护参数显示：周期表（с）、反应性表（β）
- 保护投/切开关（带铅封）
- 控制棒棒位指示（240 个灯，简化为组指示）

**区域 3 — 涡轮控制**
- 涡轮转速表、发电机功率表、主蒸汽阀控制、惰转试验相关开关（场景 2）

**区域 4 — 报警信号**
- 灯阵（~100 个报警灯，2 列）、警铃确认按钮、事故报警总灯、辐射监测仪（场景 3）

**区域 5 — 辅助系统**
- 冷却水系统阀门、应急堆芯冷却（САОР）开关、通风系统、氙浓度显示（场景 1 关键）

**区域 6 — 电气**
- 厂用电状态灯、柴油发电机状态（场景 2/3）、电压/频率表

**操作台（面板下方）**
- 模式钥匙开关、电话（拿起来听/说）、记录板（拿起来写）、规程手册（拿起来翻）、时间控制

**顶部灯带**
- "БЛОК РАБОТАЕТ"（机组运行）、"АЗ"（保护动作）、"ПОЖАР"（火灾）、总报警闪烁灯

### 导航方式

- 无标签页。无小地图。
- 导航 = 平移。
- 但提供"快速跳转"：键盘 1–6 = 跳到对应区域；双击区域标题 = 聚焦；报警触发时，对应区域的灯闪烁（玩家循着灯找过去——这是真实的方式）
- 报警引导（辅助，默认开）：报警触发时，屏幕边缘出现方向指示（箭头指向报警区域，红色，微弱闪烁）；点击箭头 = 跳转到报警区域；可在设置里关闭

### 操作确认机制

危险操作需要二次确认（真实核电站也有）：

- **AZ-5**：先打开保护罩（拖拽罩子），再按按钮
- **保护投/切**：先"破铅封"（点击铅封，铅封碎裂动画），再拨开关
- **САОР 切除**：同上

确认不是弹窗。是物理动作。

## 手持物件（电话 / 记录板 / 手册）

### 拿起 / 放下

- 点击物件 = 拿起：物件从面板上"浮起"，放大到屏幕中央前景；背景变暗（不是黑，是 30% 暗）；面板仍可操作（物件不遮挡全部屏幕，占 60% 宽）；音效：拿起的声音（纸/塑料/听筒）
- 放下：点击物件外的区域 = 放下；按 Esc = 放下；物件缩小回原位；音效：放下的声音
- 同时只能拿一件。拿着电话时不能拿手册（真实：你只有两只手，但一只要扶面板）。

## 时间控制（面板外）

### 位置

屏幕右下角，面板外：

```
┌─────────────────────────────┐
│  ⏱  ×1   ×5   ×10   ×30    │
│  当前: ×5                   │
│  [ ] 加速  [ ] 减速          │
└─────────────────────────────┘
```

- 半透明，不抢注意力
- 点击倍率 = 切换
- [ ] 键 = 循环切换
- 事故触发时，自动切回 ×1（强制，不可调），显示一行小字："Аварийный режим. Время реальное."

### 时间加速的物理意义

加速影响：氙浓度变化、温度变化、泵惰转
不加速：中子通量变化（点堆方程，毫秒级）、报警响应计时（评分用，必须实时）、音频（加速时音频不变调，只是事件更密集）

实现：模拟以固定 dt=10ms 运行。加速 = 每帧运行 N 个 dt。中子动力学子步长更小（dt=0.1ms），内部细分。

## 渲染方案

### 技术选型：Canvas 2D + DOM Overlay

分层：

| 层 | 内容 | 技术 |
|----|------|------|
| Layer 0 — 背景 | 控制室环境、CRT 辉光、指示灯辉光、事故屏幕震动 | Canvas |
| Layer 1 — 面板 | 面板底板、所有控件、仪表指针动画、灯闪烁 | Canvas |
| Layer 2 — 前景物件 | 手持物件、放大动画 | Canvas |
| Layer 3 — DOM Overlay | 悬停提示、电话对话文字、记录板输入框、手册文字、时间控制 UI、报警方向指示 | DOM |

为什么 Canvas 画控件、DOM 画文字：
- Canvas 画 200 个控件 + 60fps 动画 = 没问题
- Canvas 画中文/俄文文字 = 丑（无排版、无换行）
- DOM 画文字 = 原生排版、可选中、无障碍
- 输入框必须是 DOM（Canvas 无法输入）

### 面板绘制策略

面板 12m 宽，但视口最多显示 3m。只绘制可见区域的控件（视口裁剪）。

每帧：计算视口对应的面板坐标范围 → 只绘制范围内的控件（~50 个，不是 200 个）→ 仪表指针每帧更新角度 → 灯状态变化时重绘（不每帧）→ 辉光预渲染到 offscreen canvas，叠加

性能目标：桌面 60fps，移动端 30fps（可降低辉光质量）

### 仪表渲染

仪表 = 表盘（预渲染图片）+ 指针（每帧旋转）

表盘预渲染：刻度、数字、红区、玻璃反光 — 静态，画一次
指针动画：不是瞬间跳到目标值，有惯性：`angle += (target - angle) * 0.1`；加轻微抖动：`angle += sin(t * 20) * 0.002`

自记笔（功率记录仪）：一条纸带，随时间向左移动，笔尖画功率曲线。纸带是 offscreen canvas，每帧追加一个点。

### 灯渲染

灯状态：灭（暗灰）、亮（颜色 + 辉光）、闪烁（亮/灭交替，1Hz 或 2Hz）

辉光：预渲染径向渐变到 offscreen canvas，亮灯时叠加（`globalCompositeOperation = 'lighter'`），闪烁灯辉光随状态开关。

灯阵（报警区 ~100 个灯）：每个灯 8×8px + 标签。标签文字用 DOM overlay 或预渲染成图片（俄文短标签）。

## 移动端适配

### 原则

移动端不是"缩小版"。是"重新布局版"。

核心差异：
- 屏幕小 → 不能自由平移（误触多）
- 无悬停 → 长按代替
- 手指粗 → 控件最小触控区 44×44px
- 单手操作 → 关键控件放底部

### 移动端布局

竖屏（主要）：

```
┌─────────────────────┐
│  [当前区域面板]      │  ← 上半屏：面板（可左右滑动切换区域）
│                     │
│                     │
├─────────────────────┤
│  [区域切换标签]      │  ← 中部：1-6 区域标签（滑动切换）
├─────────────────────┤
│  [快捷操作栏]        │  ← 底部：电话/记录板/手册/时间
│  ☎ 📋 📖 ⏱          │     AZ-5 常驻底部
│  [АЗ-5]             │
└─────────────────────┘
```

- 面板区域：左右滑动切换区域（不是自由平移）
- 区域内：双指缩放
- 控件：自动放大到 44px 触控区
- 长按 = 悬停提示

横屏：与桌面相同（自由平移+缩放），控件触控区仍 44px。

### 移动端简化

- 第一人称模式：移动端不可用
- 键盘快捷键：不适用
- 悬停提示：长按 500ms
- 手持物件：全屏显示（不是 60%）
- 辉光质量：降低（性能）

## 无障碍

- 全键盘可操作（Tab/Enter/方向键）
- 焦点指示清晰（白框）
- 屏幕阅读器：每个控件有 aria-label（俄文+中文）
- 灯闪烁：提供"减少闪烁"选项（闪烁改为常亮+边框）
- 颜色盲：灯不只靠颜色区分（有文字标签）
- 字体大小：可调（DOM overlay 部分）
- 字幕：电话对话有文字（本来就是文字）
