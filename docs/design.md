# RBMK-1000 模拟器 — 设定文档

## 游戏定位

第一人称核电站操作模拟。玩家扮演切尔诺贝利核电站第四机组的站长，在 1986 年 4 月的背景下，负责反应堆的日常运行、安全管理，并最终面临是否进行安全试验的选择。

## 核心体验

- **真实的物理模拟**：中子动力学、氙毒、空泡系数、温度反馈、AZ-5 瞬态
- **运营压力**：发电指标、设备维护、人员管理、上级信任
- **决策后果**：每一个操作都有物理和经济上的连锁反应
- **历史再现**：可完整经历切尔诺贝利事故的决策链

## 玩家体验流程

1. 启动游戏 → 选择难度
2. 熟悉仪表盘和操作面板
3. 启动反应堆 → 提升功率
4. 日常运营：调棒、调泵、维护、换料
5. 应对随机事件和设备故障
6. 触发安全试验任务链
7. 在决策点做出选择
8. 多种结局：正常运营、事故、经济崩溃、政治撤职

## 核心循环

```
玩家操作 → 修改 STATE → 物理步进 → 更新显示 → 等待下个操作
```

每 0.5 秒步进一次物理（对应游戏内约 15 分钟），玩家可随时介入。

## 设计原则

1. **物理先行**：所有游戏机制建立在物理模拟之上
2. **操作即后果**：无"正确"操作，只有权衡
3. **信息不完美**：仪表有误差、延迟、故障
4. **压力渐进**：难度不是通过数值堆叠，而是通过多种压力源叠加

## 红线

- 不美化核事故
- 不简化操作过程
- 不回避辐射后果

## 世界观

1986 年 4 月，切尔诺贝利核电站，列宁核电站第四机组。RBMK-1000 型反应堆，正空泡系数，石墨慢化，沸水冷却。

## 各系统设计意图

| 系统 | 意图 |
|------|------|
| 中子动力学 | 让玩家感受反应堆对操作的响应延迟和非线性 |
| 热工水力 | 让空泡系数成为核心风险 |
| 氙毒 | 强制玩家规划功率变化，不能随意启停 |
| 汽轮机 | 让发电效率与反应堆功率解耦 |
| 经济/政治 | 制造"安全生产 vs 完成指标"的核心矛盾 |
| 人员 | 让玩家不能只关注反应堆，还要关心操作员状态 |
| 安全试验任务链 | 让历史事件以可交互的方式呈现 |

## 难度/终局设计意图

- 简单难度：容错高，设备可靠，适合学习
- 普通难度：平衡体验
- 困难难度：设备频繁故障，政治压力大

终局不是"失败"，而是各种压力源叠加导致的失控。

## 情绪曲线

1. 平静期：学习操作，熟悉系统
2. 紧张期：处理事件，应对故障
3. 危机期：安全试验决策，事故应对
4. 结局期：承受后果，评价总结
