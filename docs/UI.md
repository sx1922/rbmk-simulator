## 1 · 范围

游戏内所有"浮在仿真画面之上"的 UI 元素。不含主菜单（MENU-01 已定义）、不含 HUD 常驻仪表（属于仿真渲染层）。

本文档覆盖：

| 浮层 | 触发源 |
|------|--------|
| 电话浮层 | 场景引擎 phone 动作 |
| 对话浮层 | 场景引擎 dialogue 动作 |
| 暂停菜单 | 玩家 Esc |
| 操作日志浮层 | 玩家 Tab |
| 规程翻阅浮层 | 玩家 F1 / 场景引擎 props 动作 |
| 分支提示（无 UI） | 场景引擎 branch 动作 |
| 终局过渡 | App.endGame() |

## 2 · 浮层通用规则

### 2.1 层级（z-order）

| z | 内容 |
|---|------|
| 4-5 | CRT 扫描线/暗角（菜单/设置屏内） |
| 10 | 菜单铆钉装饰 |
| 50 | 熔毁覆盖层（`#room.meltdown::after`） |
| 100 | 桌面道具浮层（`#prop-overlay`） |
| 200 | 规程手册浮层（`#manual-overlay`） |
| 300 | 关于面板（`#about-overlay`） |
| 400 | **电话浮层**（新增） |
| 500 | **对话浮层**（新增） |
| 600 | **暂停菜单**（新增） |
| 700 | **终局过渡**（新增） |
| 9997 | 主菜单（`#new-menu`） |
| 9999 | 设置屏（`#settings-overlay`） |

新增浮层使用 400-700 区间，低于菜单/设置但高于现有游戏内浮层，互不冲突。

### 2.2 通用视觉

- 背景：半透明遮罩（rgba(0,0,0,0.6)），不是全黑——你还能看见后面的仪表盘在闪
- 卡片：CRT 屏体风格（暗角 + 扫描线），不是"网页弹窗"
- 边框：1px 琥珀色描边 + 四角小铆钉装饰
- 出现动画：从中心水平亮线展开（CRT 通电感），150ms
- 消失动画：收缩为水平亮线，100ms
- 字体：IBM Plex Mono（正文）+ Oswald（标题/人名）

### 2.3 通用交互

| 规则 | 说明 |
|------|------|
| 浮层出现时 | 仿真 tick 不冻结（电话来了堆还在跑） |
| 暂停菜单例外 | 暂停时 tick 冻结 |
| 键盘焦点 | 浮层出现时焦点转入浮层，关闭后焦点回仿真操作 |
| 同时最多一个 | 电话来了时 Дятлов 不会同时说话（场景引擎保证时序） |

## 3 · 电话浮层

### 3.1 触发

场景引擎返回 `{ type: 'phone', from, text, duration }`。

### 3.2 布局

屏幕右上角，不遮中央仪表盘。

```
                    ┌─────────────────────────┐
                    │ ☎ ВХОДЯЩИЙ / 来电        │
                    │                         │
                    │ 调度                    │
                    │ "基辅问试验什么时候      │
                    │  开始。"                │
                    │                         │
                    │ ⏎ 接听    Esc 忽略      │
                    └─────────────────────────┘
```

### 3.3 状态机

```
RINGING → (⏎) → ACTIVE → (duration 到 / ⏎) → CLOSED
   │
   └─ (Esc / 超时 10s) → MISSED → CLOSED
```

| 状态 | 表现 |
|------|------|
| RINGING | 卡片出现，标题闪烁，铃声循环 |
| ACTIVE | 文本逐字打出（打字机效果，30ms/字），铃声停 |
| CLOSED | 卡片收缩消失 |
| MISSED | 卡片变暗，显示"未接"，2s 后消失 |

### 3.4 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| from | string | 来电者名称（显示用） |
| text | string | 通话内容 |
| duration | number | ACTIVE 状态持续毫秒（默认 5000） |
| ringTimeout | number | RINGING 超时（默认 10000） |
| urgent | boolean | true = 红色边框 + 急促铃声 |

### 3.5 未接电话后果

未接不阻断游戏。但场景引擎可设 flag：

```json
{ "type": "flag", "key": "phone_01_missed", "value": true }
```

后续事件可据此改变对话（"你刚才为什么不接电话？"）。

### 3.6 声音

| 状态 | 音效 |
|------|------|
| RINGING | 老式转盘电话铃声，循环，间隔 1.5s |
| ACTIVE | 打字机逐字音 + 轻微电流底噪 |
| CLOSED | 挂断"咔" |
| MISSED | 铃声渐弱消失 |

## 4 · 对话浮层

### 4.1 触发

场景引擎返回 `{ type: 'dialogue', speaker, text, choices[] }`。

### 4.2 布局

屏幕下方 1/3，全宽。像控制台底部的对讲机面板。

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  ДЯТЛОВ                                                      │
│  "功率多少了？"                                              │
│                                                              │
│  ┌─────────────────────┐  ┌─────────────────────┐           │
│  │ 1. 30 兆瓦。        │  │ 2. （沉默）         │           │
│  └─────────────────────┘  └─────────────────────┘           │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 4.3 状态机

```
APPEAR → TYPING → WAITING → (选择) → RESPONSE → CLOSED
```

| 状态 | 表现 |
|------|------|
| APPEAR | 面板从底部滑入，100ms |
| TYPING | 文本逐字打出（25ms/字） |
| WAITING | 选项高亮可交互，等待玩家 |
| RESPONSE | 玩家选择后，对方回复（若有），再逐字打出 |
| CLOSED | 面板滑出，200ms |

### 4.4 选项交互

| 按键 | 行为 |
|------|------|
| ↑↓ 或 1/2/3 | 选择选项 |
| ⏎ | 确认选择 |
| Esc | 不选（等同于"沉默"选项，若存在） |
| 超时（30s） | 自动选择默认项（通常是沉默/不回应） |

### 4.5 无选项对话

若 choices 为空或不存在，对话为单向通知：

```
┌──────────────────────────────────────────────────────────────┐
│  АКИМОВ                                                      │
│  "САОР 已按规程断开。"                                       │
│                                                              │
│                                    ⏎ 确认                    │
└──────────────────────────────────────────────────────────────┘
```

按 ⏎ 或等 5s 自动关闭。

### 4.6 说话人视觉区分

| 说话人 | 名字颜色 | 备注 |
|--------|----------|------|
| Дятлов | 警示红 | 压力来源 |
| Акимов | 琥珀 | 同事 |
| Топтунов | 琥珀 | 同事 |
| 调度 / 不明 | 冷绿 | 外部 |
| 旁白 / 系统 | 灰白 | 非角色 |

### 4.7 声音

| 事件 | 音效 |
|------|------|
| 面板出现 | 对讲机接通"嘶—" |
| 逐字打出 | 极轻的纸带打印声（可选，默认关） |
| 选择确认 | 轻"咔" |
| 面板关闭 | 对讲机断开"嘶—" |

## 5 · 暂停菜单

### 5.1 触发

游戏内按 Esc（且无其他浮层活跃时）。

### 5.2 布局

屏幕中央卡片。

```
┌─────────────────────────────────┐
│                                 │
│  ПАУЗА / 暂停                   │
│                                 │
│  ▸ 继续值班                     │
│    整定（设置）                 │
│    结束值班                     │
│                                 │
│  Esc 继续                       │
│                                 │
└─────────────────────────────────┘
```

### 5.3 行为

| 选项 | 行为 |
|------|------|
| 继续值班 | 关闭浮层，恢复 tick |
| 整定 | 打开设置屏（复用 MENU-01 §5 组件），设置屏 Esc 返回暂停菜单 |
| 结束值班 | 弹确认（见 FLOW-01 §8.2），确认 → App.endGame('VOLUNTARY') |

### 5.4 特殊规则

- 暂停时仿真 tick 冻结
- 暂停时场景引擎时钟冻结
- 暂停时环境音效降低 50%（不静音，保持"机器还活着"的感觉）
- 终局过渡期间（ENDING 状态）Esc 无效，不弹暂停

## 6 · 操作日志浮层

### 6.1 触发

玩家按 Tab（按住展开，松开收起）。或场景引擎 log 动作写入时，右下角短暂闪现最新一条。

### 6.2 布局（Tab 按住）

屏幕左侧，半透明，不遮中央。

```
┌─────────────────────────────────┐
│ ЖУРНАЛ / 操作日志               │
│                                 │
│ 01:23:45  按下 АЗ-5            │
│ 01:23:44  功率 200 MW ↑        │
│ 01:23:40  拔棒 ×12             │
│ 01:23:12  Дятлов: "拔。"       │
│ 01:22:58  空泡份额 45%         │
│ 01:22:30  电话：调度（未接）    │
│ 01:20:00  接班                 │
│                                 │
│ ↑↓ 翻页    Tab 关闭            │
└─────────────────────────────────┘
```

### 6.3 日志条目格式

```json
{
  "time": "01:23:45",
  "text": "按下 АЗ-5",
  "type": "action",
  "color": "amber"
}
```

| type | 颜色 | 示例 |
|------|------|------|
| action | 琥珀 | 玩家操作 |
| phone | 冷绿 | 电话记录 |
| dialogue | 灰白 | 对话摘要 |
| system | 灰 | 系统消息 |
| alarm | 警示红 | 警报 |

### 6.4 闪现提示

新日志写入时，右下角短暂显示最新一条（2s 淡出），不需要按 Tab：

```
                              ┌──────────────────────┐
                              │ 01:23:45 按下 АЗ-5   │
                              └──────────────────────┘
```

## 7 · 规程翻阅浮层

### 7.1 触发

- 玩家按 F1（主动翻阅）
- 场景引擎 `{ type: 'props', action: 'show_manual', page: 47 }`（被动触发）

### 7.2 布局

全屏覆盖（z=200，复用现有 `#manual-overlay`），模拟翻开一本纸质规程。

```
┌──────────────────────────────────────────────────────────────┐
│  РЕГЛАМЕНТ / 规程                          стр. 47 / 312    │
│                                                              │
│  § 4.3.2  反应性事故工况下的操作限制                         │
│                                                              │
│  4.3.2.1  当 ORM 低于 26 根等效棒时，操纵员                  │
│           应立即停堆并报告值长。                              │
│                                                              │
│  4.3.2.2  禁止在 ORM < 15 根时继续提升功率。                 │
│                                                              │
│  [!] 第 47 页边缘有手写批注：                                │
│      "这条在 83 年修订时改过。之前是 30 根。"                │
│                                                              │
│                                                              │
│  ← → 翻页    F1 / Esc 关闭                                  │
└──────────────────────────────────────────────────────────────┘
```

### 7.3 交互

| 按键 | 行为 |
|------|------|
| ← → | 翻页 |
| F1 / Esc | 关闭 |
| 数字键 | 跳转页码（输入后 ⏎） |

### 7.4 叙事钩子

特定页面包含手写批注（[!] 标记）。玩家翻到该页时：
- 设置 flag：`discovered_page_47 = true`
- 结算画面可引用（FLOW-01 §6.3）
- 不弹提示、不成就弹窗——你自己看见了就看见了

### 7.5 视觉

- 背景：泛黄纸张纹理（不是 CRT 绿——这是纸，不是屏幕）
- 字体：IBM Plex Mono（正文）+ 手写体（批注，用 Caveat 或类似）
- 翻页动画：轻微纸张翻动声 + 页面横移

## 8 · 分支提示（无 UI）

### 8.1 设计原则

分支不弹选择框。玩家通过操作表达选择。

但需要给玩家"正在被观察"的暗示：

### 8.2 暗示手段

| 手段 | 表现 |
|------|------|
| 压力层级变化 | Дятлов 走到你身后（压力 level 2），不说话，就站着 |
| 环境音变化 | 底噪微微升高，继电器咔咔频率加快 |
| 日志提示 | 操作日志写入："等待操纵员决定。" |
| 超时暗示 | 超时前 30s，电话铃响一声（催促感） |

### 8.3 绝对不做的事

- ❌ 不弹"请选择 A 或 B"
- ❌ 不在屏幕上显示倒计时
- ❌ 不用任何 UI 元素暗示"这是分支点"

玩家应该事后才意识到"刚才那一刻是一个选择"。

## 9 · 终局过渡

### 9.1 触发

App.endGame() 被调用后，进入 ENDING 状态。

### 9.2 各类型过渡

| 终局类型 | 视觉 | 音频 | 时长 |
|----------|------|------|------|
| MELTDOWN | 屏幕白化 → 结构撕裂 → 红光脉冲 → 渐暗至黑 | 低频轰鸣 + 金属撕裂 + 盖革计数爆响 → 寂静 | 3s |
| SCENARIO_END（爆炸） | 同上 | 同上 | 3s |
| SCENARIO_END（安全） | 荧光灯逐盏熄灭，CRT 正常渐暗 | 荧光灯"嗒、嗒、嗒"熄灭 + 底噪渐无 | 2s |
| VOLUNTARY | CRT 缩成水平亮线 → 亮点 → 消失 | 继电器断开"咔" + 消磁"嗡—" | 1.5s |
| CHALLENGE_END | 计时器数字定格 → 闪一下 → 渐暗 | 计时器停止"嘀" | 1.5s |
| TIMEOUT | 计时器闪红 × 3 → 蜂鸣 → 渐暗 | 三声短蜂鸣 + 长蜂鸣 | 2s |

### 9.3 过渡期间

- 不接受任何输入
- 不显示任何 UI 浮层
- 过渡完成后自动进入 DEBRIEF 状态

## 10 · UIManager 接口

```js
class UIManager {
  constructor(app) {}

  showPhone({ from, text, duration, urgent })
  // 返回 Promise，resolve 时携带 { status: 'answered' | 'missed' }

  showDialogue({ speaker, text, choices, timeout })
  // 返回 Promise，resolve 时携带 { choice: string | null }

  showPause()
  // 返回 Promise，resolve 时携带 { action: 'resume' | 'settings' | 'quit' }

  pushLog({ time, text, type })
  showLogPanel()
  hideLogPanel()

  showManual(page)
  hideManual()

  armBranch(config)
  disarmBranch()

  playEnding(type)
  // 返回 Promise，resolve 时过渡完成
}
```

所有浮层方法返回 Promise。场景引擎通过 await 控制时序：

```js
await this.ui.showPhone({ from: '调度', text: '...' });
// 电话结束后才继续下一个事件
```

## 11 · 实现顺序

| 步 | 任务 | 依赖 |
